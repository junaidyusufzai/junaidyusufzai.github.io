Publications

  • 2026
    HPCRNet: A Hierarchical Pyramid Context Refinement Framework for Interpretable Hip Fracture Analysis.
    Applied Soft Computing (ASOC), In revision.

    This paper introduces HPCRNet, a deep learning framework for multi-class hip fracture classification from radiographs, where fracture patterns are subtle, highly localized, and spread across imbalanced subtypes. Instead of relying on global dependency modeling, which can bring in redundant background information, it uses a Hierarchical Pyramid Context Refinement (HPCR) attention mechanism embedded in residual networks, incorporating supervised contrastive learning to improve separability between fracture subtypes. HPCRNet outperforms recent attention mechanisms and architectures, and Grad-CAM analysis shows its attention concentrating on diagnostically relevant fracture regions.
